⚙️ Trạm 02 • Tối ưu 🎯

Tối ưu hoá ứng dụng

📊 Trạm 03 • Dữ liệu 🛰️

🔬 Trạm 04 • Mô phỏng 🌌

Từ chuyển động, tăng trưởng, lan truyền đến cân bằng: biến công thức thành trải nghiệm tương tác.

Chạy mô phỏng → Run system
🌍 Trạm 05 • Xã hội 🏙️
